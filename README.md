# URL SHORTENING SERVICE
## Description
A simple RESTful API that allows users to shorten long URLs. The API provide endpoints to create, retrieve, update, and delete short URLs. 
TO implement with a frontend : It should also provide statistics on the number of times a short URL has been accessed.
This project is based on https://roadmap.sh/projects/url-shortening-service

You should install POSTMAN to test API endpoints, MySQL workbench and Java.
On the applicattion.properties insert the database url, user name and password.
